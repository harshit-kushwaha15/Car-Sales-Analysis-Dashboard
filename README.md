# Car-Sales-Analysis-Dashboard
Car Sales Analysis Dashboard is a data analytics project focused on analyzing car sales performance, pricing, customer trends, and regional insights. Built using Excel, SQL, Python, Pandas, and Power BI, it includes data cleaning, KPI analysis, interactive visualizations, and dashboards for data-driven decision-making.
# 🚗 Car Sales Analysis Dashboard

## 📌 Project Overview

**Car Sales Analysis Dashboard** is a data analytics and business intelligence project developed to analyze car sales performance and identify important sales trends, customer preferences, pricing patterns, and regional performance.

The project transforms raw car sales data into meaningful insights using data cleaning, analysis, KPI calculation, and interactive data visualization.

## 🎯 Objectives

* Analyze overall car sales performance.
* Identify sales trends and patterns.
* Analyze car models, brands, and categories.
* Study pricing and sales relationships.
* Compare regional sales performance.
* Monitor key performance indicators (KPIs).
* Create an interactive dashboard for data-driven decision-making.
